# 📊 HR Workforce Analytics & Employee Performance Dashboard

## 📌 Project Overview

The **HR Workforce Analytics & Employee Performance Dashboard** is an end-to-end data analytics project developed to analyze employee workforce data and generate actionable insights for HR decision-making.

The project focuses on **employee performance, workforce productivity, employee attrition, departmental trends, salary distribution, and attendance patterns**. It integrates **Python, SQL, statistical analysis, and Power BI** to transform raw employee data into meaningful business insights.

The primary objective is to help HR teams understand workforce trends, monitor key HR performance indicators, identify factors associated with employee turnover, and support data-driven decisions related to **employee retention, workforce planning, and productivity improvement**.

---

## 🎯 Business Problem

Organizations require reliable workforce insights to effectively manage employee performance, productivity, and retention. Manual analysis of employee information can make it difficult to identify attrition patterns, departmental differences, salary trends, and performance-related factors.

This project addresses these challenges by developing a centralized HR analytics solution that enables stakeholders to:

- Monitor workforce performance
- Analyze employee attrition and retention
- Compare departments
- Evaluate salary and attendance patterns
- Measure workforce productivity
- Identify potential factors contributing to employee turnover
- Support evidence-based HR decision-making

## 🧹 Data Preparation

The employee dataset was prepared using **Python and Pandas** in **Jupyter Notebook**.

### Data Preparation Steps

- Imported the employee dataset
- Inspected dataset structure and column information
- Identified missing and null values
- Checked for duplicate records
- Validated categorical and numerical fields
- Corrected inconsistent data types
- Converted date columns into appropriate date formats
- Standardized data where required
- Performed data quality and consistency checks
- Prepared the cleaned dataset for analysis and Power BI

The final cleaned dataset was exported and used for further analytical processing and dashboard development.

## 📊 HR Key Performance Indicators

The project evaluates the following key HR performance indicators:

| KPI                         | Description                                                                    |
| --------------------------- | ------------------------------------------------------------------------------ |
| **Employee Retention Rate** | Measures the proportion of employees retained within the organization          |
| **Employee Attrition Rate** | Measures the proportion of employees who have left the organization            |
| **Average Salary**          | Represents the average compensation across the workforce                       |
| **Performance Score**       | Represents overall employee performance based on available performance metrics |
| **Department Productivity** | Enables comparison of productivity across departments                          |

These KPIs provide HR stakeholders with a consolidated view of workforce health and organizational performance.
